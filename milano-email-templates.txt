========================================================
ملفات قوالب إيميلات متجر ميلانو - Firebase Console
========================================================
طريقة الاستخدام:
1. افتح Firebase Console > Authentication > Templates
2. اختار القالب (Email verification / Password reset / Email change / MFA)
3. الصق Sender name + Subject + الـ HTML في خانة Message
4. Save

ملاحظة مهمة عن [[actionUrl]]:
لو ظهر حرفي (مش رابط) في المعاينة، من شريط أدوات المحرر
اختار Insert > Action URL عشان تحط الرابط الصح.
المتغيرات %EMAIL% و %APP_NAME% بتتكتب عادي.

لو المحرر رفض الحفظ: SMTP Enable off > Save > الصق القوالب >
Save > Enable on > أعد إدخال قيم SMTP (smtp.gmail.com / 465 / SSL /
milanoyemen@gmail.com / باسورد التطبيق).
